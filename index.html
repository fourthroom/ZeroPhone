📍 Enable Location Access

To center maps on your current location, allow location access in your device settings:

iPhone / iPad:
1. Open Settings → Privacy & Security
2. Tap Location Services → Safari / Chrome
3. Select While Using the App

Desktop Chrome / Safari:
Tap the Lock / Sliders icon next to fourthroom.org in your address bar → set Location to Allow.
